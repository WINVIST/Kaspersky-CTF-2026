# Garden

**Категория:** Web

Задача с сёги. Нам дают исходники Flask-приложения, а в базе у пользователя `admin` первым ходом лежит флаг.

## Разбор

### Где SQLi

Ходы сохраняются вот так:

```python
query = f"""
    INSERT INTO game_moves (user_id, move, created_at)
    VALUES ('{self.user_id}', '{move_usi}', datetime('now'))
"""
```

`move_usi` вставляется через f-string, но перед этим ход проверяет `cshogi`. К обычному ходу просто дописать кавычку нельзя — парсер его отвергает.

Долго смотрел на Flask session, перебирал возможный `SECRET_KEY` и даже успел проверить вариант с Werkzeug PIN. Это оказалось не туда.

### Drop move

В сёги захваченную фигуру можно вернуть на доску. Такой ход выглядит, например, как `S*1b`.

Оказалось, что `cshogi` для drop move разбирает только первые четыре символа, а хвост игнорирует. Для шахматного движка это валидный ход:

```text
S*1b
```

а SQLite получает уже всю строку:

```text
S*1b' ... SQL ...
```

Сначала нужно было реально захватить фигуру, иначе в списке legal moves не будет ни одного drop. Скрипт играет случайные легальные ходы, предпочитая взятия, пока такой ход не появится.

### Oracle

Первый вариант был boolean-based: при true INSERT проходил, при false падал на `NOT NULL`. Он работал, но успешная проверка сохраняла мусорный ход в БД и ломала дальнейшее состояние партии.

Поэтому переделал на time-based. Оба исхода теперь заканчиваются ошибкой, но в true-ветке SQLite считает большой `randomblob`:

```sql
' OR ((CASE WHEN (<condition>)
       THEN length(randomblob(100000000))
       ELSE 0 END) * NULL), datetime('now')) --
```

Все ответы имеют статус 500 и ничего не сохраняют. Разница только во времени. В начале отдельно измерял четыре быстрых и четыре медленных запроса, а потом для каждого бита брал медиану трёх измерений.

Флаг лежал здесь:

```sql
SELECT move
FROM game_moves
WHERE user_id='admin'
ORDER BY id ASC
LIMIT 1
```

Один символ из-за шума сначала получился неправильным (`n` вместо `m`). Перепроверил его девятью запросами и потом отдельным условием сравнил весь флаг целиком.
